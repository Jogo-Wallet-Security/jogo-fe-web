# Jogo - AI-Powered Web3 Wallet Security

Jogo is an AI-powered wallet security platform that protects Web3 users from phishing, malicious approvals, and drain attacks. It intercepts and simulates every transaction before you sign, monitors the mempool for threats in real time, and autonomously rescues your assets to a safe wallet when danger is detected.

**Live preview:** https://f88f4a20.jogo-fe-web.pages.dev/

## Tech Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS v4
- Motion (Framer Motion) for animations
- Biome for formatting
- ESLint for linting
- Cloudflare Pages for deployment

## Getting Started

```bash
pnpm install
pnpm dev
```
